Многофункциональная экосистема для Telegram (**12 разделов, 50+ утилит, 4 аркадные игры, энциклопедии знаний и соцсеть**), объединяющая:
1. **Telegram-бота на `aiogram 3.x`** — динамический Single-Message HUD, умный авто-приём любых величин/файлов/текста без команд (**Smart Omni-Input**), **Inline-режим (`@multi_tg_bot запрос`)** и систему рангов.
2. **Telegram Mini App** — интерфейс на **React 19 + TypeScript + Tailwind CSS**, синхронизированный с ботом через единую SQLite WAL базу данных.
3. **Живой симулятор Telegram** прямо в браузере на порту `8000`.

## ☑️ Доска задач

Доска задач в рабочем пространстве поддерживает категории (общее, работа, личное, учёба, здоровье и покупки), приоритеты (обычный, важный, срочный), необязательный срок и оценку времени от 0 до 1440 минут. Сводка показывает просроченные задачи, задачи на сегодня и суммарную оценку оставшейся работы. Поиск работает по тексту; фильтры доступны по статусу, сроку и категории, а сортировка — по сроку, приоритету или времени добавления. Список можно выгрузить в CSV.

Существующие действия остаются доступны: добавить, отметить/снять выполнение, удалить задачу и очистить выполненные. API принимает `POST /api/workspace/todos` с `text`, `priority`, `due_date`, `category` и `estimated_minutes`; обновление полей выполняется через `PATCH /api/workspace/todos/{id}`. Срок передаётся в ISO-формате `YYYY-MM-DD`, пустой/`null` срок его снимает. Миграция добавляет новые столбцы к существующей SQLite-таблице, сохраняя старые задачи и назначая им категорию «Общее».

## 💳 Финансовый планировщик и общий счёт

Финансовый калькулятор в Mini App поддерживает вклады, цель накоплений с поправкой на инфляцию, аннуитетный и дифференцированный кредит, досрочные ежемесячные платежи, полный график амортизации и CSV-выгрузку. Прогноз — сценарная математика, а не банковская оферта: ставки, комиссии, налоги и реальные условия договора могут отличаться.

Раздел общего счёта умеет работать в трёх режимах:
- **Равные или взвешенные доли** — укажите, сколько каждый уже оплатил; вес `1` означает обычную долю, `0.5` — половину, `2` — двойную.
- **Разбивка по позициям** — добавьте блюда или услуги, назначьте плательщика и отметьте, кто делил конкретную позицию. Чаевые распределяются пропорционально суммам долей.
- **Расчёт взаимозачёта** — показывает баланс каждого участника и компактный список переводов. Копирование переводов и CSV-экспорт доступны из интерфейса.

Для деления счёта поддерживаются коды валют `RUB`, `EUR`, `USD`, `GBP`, `CHF`, `PLN`, `TRY`, `KZT`, `GEL`, `AMD`, `UZS`. Выбор валюты только меняет обозначение единицы: **конвертации по курсу нет**, все суммы в одном запросе должны быть в выбранной валюте.

### API общего счёта

Равный или взвешенный расчёт принимает участников с уже оплаченными суммами:

```bash
curl -X POST http://localhost:8000/api/v2/v5/bill-split \
  -H 'Content-Type: application/json' \
  -d '{"currency_code":"EUR","tip_pct":10,"entries":[{"name":"Анна","paid":42.50,"share_weight":1},{"name":"Борис","paid":10,"share_weight":0.5}]}'
```

Для позиционного расчёта укажите плательщика и список участников каждой позиции:

```json
{
  "currency_code": "EUR",
  "tip_pct": 10,
  "entries": [{"name":"Анна","paid":0},{"name":"Борис","paid":0}],
  "expenses": [
    {"description":"Ужин","amount":42.50,"payer":"Анна","participants":["Анна","Борис"]},
    {"description":"Напиток","amount":8,"payer":"Борис","participants":["Борис"]}
  ]
}
```

API округляет до сотых и распределяет остаточные центы детерминированно; максимумы — 100 участников и 200 позиций за расчёт. Ответ содержит `settlements` с оплатой, долей и балансом, а также список `transfers`.
