# 🌌 NEXUS v2 • Мега-Мультитул Telegram Бот + Mini App + Аркада

Полноценная мультитул-экосистема для Telegram (**12 разделов, 50+ инструментов, 4 аркадные игры, энциклопедии знаний и соцсеть**), объединяющая:
1. **Telegram-бота на `aiogram 3.x`** — динамический Single-Message HUD (навигация редактированием одного сообщения без спама в чате), умный авто-приём любых величин/файлов/текста без команд (**Smart Omni-Input**), **Inline-режим (`@bot запрос`)** и геймификацию рангов.
2. **Telegram Mini App Studio (WebApp)** — неоморфный интерфейс на **React 19 + TypeScript + Tailwind CSS**, синхронизированный с ботом через общую SQLite WAL базу данных.
3. **Живой симулятор Telegram + Панель деплоя** прямо в браузере на порту `8000`.

## 🚀 Деплой 24/7 за ~150 ₽/мес на Amvera Cloud (или VPS Aeza) + @BotFather + Донаты

1. **Создайте бота в `@BotFather`**:
   - Отправьте `/newbot`, получите `BOT_TOKEN`.
   - Отправьте `/setinline` для включения инлайн-режима.
2. **Залейте на облачный хостинг Amvera (`amvera.ru`, ~120–190 ₽/мес)**:
   - В корне проекта уже лежит готовый файл **`amvera.yml`** (Python 3.11, порт `8000`, постоянный диск `/data` для SQLite).
   - Подключите GitHub-репозиторий к проекту в Amvera, включите бесплатный HTTPS-домен `*.amvera.io` и укажите переменные окружения `BOT_TOKEN` и `WEBAPP_URL`.
   - Укажите этот `https://ваш-проект.amvera.io` в `@BotFather` → *Bot Settings → Menu Button* — и у вашего бота появится полноценное Mini App!
3. **Подключите Донаты**:
   - Откройте раздел *«Соцсеть → Автор: QLS СЕНЯ → Изменить ссылки»* и вставьте ссылку на **DonationAlerts / Boosty / CloudTips / ЮMoney / @send**, либо принимайте встроенные **Telegram Stars (`XTR`)**.
