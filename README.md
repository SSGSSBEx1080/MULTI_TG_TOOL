# 🌌 MULTI_TG_TOOL (`@multi_tg_bot`)

<p align="center">
  <img src="assets/multi_tg_tool_avatar_1024.png" alt="MULTI_TG_TOOL Avatar" width="240" />
</p>

Многофункциональная экосистема для Telegram (**12 разделов, 50+ утилит, 4 аркадные игры, энциклопедии знаний и соцсеть**), объединяющая:
1. **Telegram-бота на `aiogram 3.x`** — динамический Single-Message HUD, умный авто-приём любых величин/файлов/текста без команд (**Smart Omni-Input**), **Inline-режим (`@multi_tg_bot запрос`)** и систему рангов.
2. **Telegram Mini App** — интерфейс на **React 19 + TypeScript + Tailwind CSS**, синхронизированный с ботом через единую SQLite WAL базу данных.
3. **Живой симулятор Telegram** прямо в браузере на порту `8000`.
